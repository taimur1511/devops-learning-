I used `ls` to list all the files and directories.

I then used `cd` to navigate into the inhere directory.

`ls -a` was used to list all fiels and directories and to not ignore hidden files. 

## What I learned 

Hidden files start with a `.` 

The man command is very useful. Initially, I didn't know how I could view or list hidden files using `ls` so I used `man ls` which opens up a general command manual for `ls`. This is where i found `ls -a` could be used to list files and not to ignore hidden files.
