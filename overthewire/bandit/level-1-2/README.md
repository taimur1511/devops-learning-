## Explanation 
I used `ls` to list the files in the current directory.  

I then used `cat ./-` to view the file `-`. 


## What I Learned 

The `./-` after `cat` tell Linux that `-` refer to a file in the current directory. 

Linux commands can interpret `-` as an option or argument.
