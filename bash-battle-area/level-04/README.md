# Level 4: File Manipulation

Mission: Create a script that copies all .txt files from the Arena directory to a new directory called Backup.

## Solution 

I used the `mkdir -p` command to create a directory called `Backup`. 

I then used `cp` to copy all txt files from `arena` into `Backup`. The * is a wildcard used to match any number of characters in a filename, allowing you to select multiple files without specifying each filename individually.

The output shows that all three txt files were copied succesfully.
