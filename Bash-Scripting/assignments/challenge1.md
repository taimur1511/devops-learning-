# Challenge 1: Basic Arithmetic Calculator

Create a script that takes two numbers as input and performs basic arithmetic operations (addition, subtraction, multiplication, division).

Requirements:
- Prompt user for two numbers
- Perform all four operations
- Display the results
- Handle division by zero

For this, I used the `read` command which allows user input followed by variables `number1` and `number2`. 

I used the `echo` command to display text in the terminal and the `read` command will prom the user to enter the first number and the second number. 

I created an `if` statement for division by 0. If the condition is true then the terminal will display "Division by 0 is not possible." `else` was used for when the condition is false. 

I used arithmetic expansion and variable assignment to calculate the result and echo them to the terminal.
