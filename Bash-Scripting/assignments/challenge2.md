# Challenge 2: File Operations Script

Create a script that automates directory and file creation.

Requirements:
- Create a directory called bash_demo
- Navigate into the directory
- Create a file called demo.txt
- Write text to the file (include current date)
- Display the file contents

I used the `mkdir` command to create a directory called bash_demo. I then navigated into that directory using the `cd` command. 

I created a file called demo.txt using the `touch` command. 

I used the `echo` command to write a message containing the current date into demo.txt. I used $(date) to get the current date and time. The `>` symbol redirects the output into the file rather than displaying it directly in the terminal.
