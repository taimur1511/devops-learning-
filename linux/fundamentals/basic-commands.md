## Basic Commands 
- pwd: Shows the full path of you current working directory
- ls: Lists files and folders in current directory 
- cd: Changes your current directory 
- cd..: Changes from current directory to parent directory 
- mkdir: Creates a new directory 
- rmdir: Deletes an empty directory 

- touch: Creates an empty file or updates an existing file timestamp 
- cp: Copies files or directories 
- mv: Moves or renames files and directories 
- rm: Deletes files or directories 
- cat: Displays content of file 
- head: Views first few lines of a file (for specific number of lines head -n 10 can be used to read the first 10 lines) 
- tail: Views last few lines (-n 10 can be used to read last 10 lines) 
- vim: edit file text 

- grep: Searches for specific text patterns inside a file or output 
- find: Locates files and folders based off criteria 
- chmod: Changes file access permissions 
- chown: changes file ownership
